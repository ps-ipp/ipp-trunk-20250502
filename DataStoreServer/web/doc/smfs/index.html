IPP-Misc: SMF Access

This page contains links to information about accessing IPP SMF files which contain the results of IPP camera stage processing.

These files are FITS format files containing multiple binary table extension sections. These which contain the photometric and astronometric measurements for the sources detected in a single Pan-STARRS exposure.

These files are the inital inputs to the PS calibration process.
