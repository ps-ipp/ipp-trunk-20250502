This page lists Ohana packages which are available as complete tarballs. There are different packages representing different subsets of the Ohana collection of software. To install these, simply run configure, make, and make install (see the installation instructions for further details). Also list on this page are the Elixir configuration tarballs, which provide information needed by some of the Elixir programs.

The following external libraries are needed for Ohana.

  • libjpeg
  • libpng
  • the readline library
  • zlib

Mana Distributions

The Mana distribution provides the libraries and components needed to compile mana, an data and image analysis tool, and the associated display tools, Kapa and Kii.
  • mana-1.1.tgz
  • mana-1.0.tgz

Elixir-Ohana Distributions

The Elixir-Ohana distribution provides the complete set of Ohana software used by the Elixir system at CFHT. To use the Elixir system, you will also need the Elixir configuration package.
  • elixir-ohana-head.tgz
  • elixir-ohana-1.6.tgz
  • elixir-ohana-1.5.tgz
  • elixir-ohana-1.4.tgz
  • elixir-ohana-1.3.tgz
  • elixir-ohana-1.2.tgz
  • elixir-ohana-1.1.tgz
  • elixir-ohana-1.0.tgz

Other library requirements for the complete Elixir system include:

  • apache
  • flips (v.2)
  • sextractor
  • Xvnc

Opihi Distributions

The Opihi distribution provides all of the opihi programs (mana, dvo, psched, pcontrol, and pclient) and the supporting programs Kapa and Kii.
  • opihi-2.3.tgz

Psched Distributions

The Psched distribution provides the related programs psched, pcontrol, and pclient. These programs are used for the Pan-STARRS IPP scheduling and parallel-processing system.
  • psched-0.1.tgz

Ohana Tools Distributions

The Ohana Tools distribution provides the various useful tools from the Ohana system, including FITS-file manipulation program, precession / coordinate coversions, and the gcompare tool.
  • ohana-tools-1.0.tgz

Elixir Configuration Distributions

The Elixir Configuratin distribution provides the configuration files needed by several of the Ohana Elixir program.
  • elixir-config-1.2.tgz
  • elixir-config-1.1.tgz
  • elixir-config-1.0.tgz
