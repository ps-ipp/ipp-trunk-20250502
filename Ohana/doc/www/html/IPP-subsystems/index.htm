The Pan-STARRS IPP is using several programs from the Ohana collection for portions of the IPP Infrastructure. These subsystems include:
  • psched: the IPP scheduler program
  • pcontrol : the IPP parallel process controller
  • pclient : the pcontrol remote client
In addition to these program, the IPP will use DVO for object photometry manipulation. IPP requires the upgraded capability which will be provided by DVO after Fall 2005, including enhanced throughput. DVO is discussed in its own section.
